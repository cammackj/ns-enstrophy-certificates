# Paper 1 Support

This folder contains the public support package for Paper 1,
`Nonlinear Phase Portrait Analysis for the Three-Dimensional Navier--Stokes
Enstrophy`.

The package includes only the rendered C-star trajectory figures used by the
manuscript.  Private Paper 1 development code, tests, exploratory logs, and
figure-generation work products are intentionally not included in this public
certificate archive.

The manuscript figures are archived as:

```text
scripts/paper_figs/fig1_cstar_trajectory.pdf
scripts/paper_figs/fig2_cstar_zoom.pdf
```

The PNG versions are included for quick inspection.
